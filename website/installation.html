Installation & Basic Usage

WebPullBook is currently in Beta and is not yet published on the Chrome Web Store or Firefox Add-ons. You can download the packaged ZIP directly below and load it in your browser with no build step.

Download Latest Package (.zip) All Releases & Checksums
Chrome • Edge • Brave • Vivaldi • Chromium

1. Chrome & Chromium Browsers

  1. Click Download Latest Package (.zip) and extract the archive to a permanent folder on your computer.
  2. Open chrome://extensions/ (or edge://extensions/ / brave://extensions/).
  3. Enable Developer mode in the top-right corner.
  4. Click Load unpacked and select the extracted folder containing manifest.json.
Mozilla Firefox 128+ (Manifest V3)

2. Mozilla Firefox (128 or Newer)

  1. Download the .zip archive using the button above (extracting is optional on Firefox).
  2. Open about:debugging#/runtime/this-firefox in Firefox 128+.
  3. Click Load Temporary Add-on... and select manifest.json (or the downloaded .zip file directly).
  4. Limitation during Beta: Temporary add-ons remain active for the current Firefox session and must be reloaded in about:debugging after restarting Firefox until the extension is signed on Mozilla Add-ons.

How to Use

Basic workflow after loading the extension in your browser:

1. Open the Target Page

Navigate to a book's table-of-contents page (or a chapter page) in your browser. If the site requires login or anti-bot verification, complete it in that tab first.

2. Launch the Workspace

Click the WebPullBook toolbar icon. The workspace tab opens and reads the active tab's DOM to fill in metadata, volumes, and chapters (applying the default cover if the page has no cover image).

3. Select Profile & Export

Choose a Reader Profile (such as Kindle Legacy for Send to Kindle, Kindle Modern for Calibre USB, or Kobo), select your chapters or volumes, and click Pack EPUB.

Installing via Git Clone & Updating

If you prefer tracking updates via Git, the repository root can be loaded directly as an unpacked extension:

To update an existing installation when a new release comes out, extract the new .zip over the same folder (or run git pull) and click reload on chrome://extensions/. Saved settings and Library entries in chrome.storage.local are preserved.
