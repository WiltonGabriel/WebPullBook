Installation & Sending Books to Your E-Reader

Start saving web stories in under two minutes. Firefox users get one-click updates via Firefox Add-ons (AMO); Chrome, Edge, and Brave users can load the official Beta ZIP package directly with no extra software.

Install on Firefox Add-ons Download ZIP (Chrome / Edge / Brave) All Releases & Checksums

1. Install in Your Browser

Pick your browser below. Updates keep all your saved settings, Reader Profiles, domain rules, and Library history intact.

Mozilla Firefox 128+ (Manifest V3)

Mozilla Firefox (128 or Newer)

  1. Open the WebPullBook page on Firefox Add-ons.
  2. Click Add to Firefox and accept the permission prompt so WebPullBook can read pages you ask it to extract.
  3. Pin the WebPullBook icon in the toolbar puzzle menu so it stays one click away.
  4. Updates: Signed updates arrive automatically from Mozilla AMO.
Chrome • Edge • Brave • Vivaldi • Chromium

Chrome, Edge, Brave & Vivaldi (Beta Package)

  1. Download the latest release .zip from GitHub Releases and unzip it into a permanent folder (do not delete that folder later).
  2. In your address bar, open chrome://extensions/ (or edge://extensions/ / brave://extensions/).
  3. Turn on Developer mode in the top-right corner.
  4. Click Load unpacked and choose the unzipped folder containing manifest.json.
Updating a Manual Chromium Install Without Losing Data

When a new release comes out, download and unzip the new package over the same folder (or run git pull) and click the circular reload arrow on WebPullBook inside chrome://extensions/. Your Reader Profiles, Library series, and Domain Rules remain preserved inside chrome.storage.local.

2. Make Your First Ebook

A normal reader workflow from web page to saved file:

Step 1: Open the Story

Open a story's table of contents (or any single chapter) in a normal tab. If the site uses a login or anti-bot screen, sign in or verify in that tab first.

Step 2: Pick Chapters & Profile

Click the WebPullBook toolbar icon. Check metadata and chapters, choose a partial range or volumes if needed, and pick your device in Reader Profile (for example Kindle Legacy, Kindle Modern, or Kobo).

Step 3: Export & Save

Enable Safe Mode for large stories, then click Pack EPUB. Finished books save straight into your Downloads folder (or custom PC folder in Chromium).

3. Transfer to Your E-Reader or App

Quick tips so covers, footnotes, and series shelves display properly on your reading device:

Amazon Kindle

  • Send to Kindle (Email / Web / App): Use Kindle (Legacy) so WebPullBook exports EPUB 2 with 1200px JPEG images accepted by Amazon's converter.
  • USB via Calibre: Use Kindle (Modern) (EPUB 3), then let Calibre convert to KFX or AZW3 before transferring over USB.

Kobo, Tolino & PocketBook

  • Export using Kobo & E-Readers (EPUB 3 with 1080px JPEG images and pop-up footnotes).
  • Copy the .epub via USB directly into your reader (or use Calibre with KoboTouch / KePub conversion if you prefer KePub pagination).

Phones, Tablets & Desktop

  • Use Modern Default for Apple Books, Thorium Reader, Calibre Viewer, Moon+ Reader, KOReader, or ReadEra.
  • Prefer reading without an app? Switch Output Format to Single-File HTML and open it directly in any mobile browser.

4. Running From Source & Developer Workflow

WebPullBook uses native ES modules with zero build step and zero runtime dependencies—the repository root loads directly as an unpacked extension in both Chromium and Firefox, while optional Node.js tooling validates every change locally.

Need private real-site E2E scripts while developing new parser adapters? Place them inside the gitignored .local-e2e/ directory—see Contributing for the full adapter and testing guide.
