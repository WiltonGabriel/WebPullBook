Installation & Basic Usage

WebPullBook is officially published on Firefox Add-ons (AMO) for Firefox 128+. Chrome Web Store submission is planned next; during Beta, Chrome, Edge, and Brave users can install the signed release package from GitHub Releases with no build step.

Install on Firefox Add-ons GitHub Releases (Chrome / Chromium) All Releases & Checksums
Mozilla Firefox 128+ (Manifest V3)

1. Mozilla Firefox (128 or Newer)

  1. Open the WebPullBook page on Firefox Add-ons.
  2. Click Add to Firefox and confirm the requested permissions.
  3. Signed updates are delivered automatically by Firefox Add-ons.
  4. For Developers: Local development builds can still be loaded temporarily in about:debugging#/runtime/this-firefox.
Chrome • Edge • Brave • Vivaldi • Chromium

2. Chrome & Chromium Browsers

  1. Download the release archive from GitHub Releases and extract it to a permanent folder on your computer.
  2. Open chrome://extensions/ (or edge://extensions/ / brave://extensions/).
  3. Enable Developer mode in the top-right corner.
  4. Click Load unpacked and select the extracted folder containing manifest.json.

How to Use

Basic workflow after loading the extension in your browser:

1. Open the Target Page

Navigate to a book's table-of-contents page (or a chapter page) in your browser. If the site requires login or anti-bot verification, complete it in that tab first.

2. Launch the Workspace

Click the WebPullBook toolbar icon. The workspace tab opens and reads the active tab's DOM to fill in metadata, volumes, and chapters (applying the default cover if the page has no cover image).

3. Select Profile & Export

Choose a Reader Profile (such as Kindle Legacy for Send to Kindle, Kindle Modern for Calibre USB, or Kobo), select your chapters or volumes, and click Pack EPUB.

For Developers: Git Clone & Updating

For developers and contributors running from source or testing changes, the repository root can be loaded directly as an unpacked extension:

End users do not need Git—use Firefox Add-ons or download the clean release .zip above. For manual Chromium updates, extract the new .zip over the same folder (or run git pull) and reload on chrome://extensions/; saved settings and Library entries in chrome.storage.local are preserved.
