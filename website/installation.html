Installation & Sending Books to Your E-Reader

Start saving web stories in under two minutes. Firefox users get one-click updates via Firefox Add-ons (AMO); Chrome, Edge, and Brave users can load the official Beta ZIP package directly with no extra software.

Install on Firefox Add-ons Download ZIP (Chrome / Edge / Brave) All Releases & Checksums

1. Install in Your Browser

Pick your browser below. Future updates keep all your saved settings, Reader Profiles, Domain Rules, and Library history intact.

Mozilla Firefox 128+ (Manifest V3)

Mozilla Firefox (128 or Newer)

  1. Open the WebPullBook page on Firefox Add-ons.
  2. Click Add to Firefox and confirm the permission prompt so WebPullBook can fetch pages you ask it to extract.
  3. Pin WebPullBook to your toolbar from the puzzle extensions icon so it stays one click away.
  4. If Firefox prompts for website access when loading your first story, allow it or grant Access your data for all websites under about:addons → Permissions.
  5. Updates: Signed updates arrive automatically via Mozilla AMO.
Chrome • Edge • Brave • Vivaldi • Chromium

Chrome, Edge, Brave & Vivaldi (Beta Package)

  1. Download the latest release .zip from GitHub Releases and unzip it into a permanent folder (for example, Documents/Extensions/WebPullBook/—do not delete or move it later).
  2. In your address bar, open chrome://extensions/ (or edge://extensions/ / brave://extensions/).
  3. Turn on Developer mode in the top-right corner.
  4. Click Load unpacked and choose the unzipped folder containing manifest.json.
Updating or Switching Computers Without Losing Your Library

When a new version ships on Chromium, unzip the new package over the same folder (or run git pull) and click the circular reload icon on WebPullBook inside chrome://extensions/. Your Reader Profiles, Library series, and Domain Rules stay intact in chrome.storage.local. Moving to another computer? Use Advanced Options → Global Backup & Restore to export your settings and Domain Rules as JSON.

2. Make Your First Ebook & Quick Setup Tips

From an open story page to a saved ebook in three straightforward steps:

Step 1: Open the Story

Visit the story's Table of Contents page (or any chapter) in a normal browser tab. If a site requires signing in or passing an anti-bot check, complete that in your tab first.

Step 2: Pick Chapters & Profile

Click the WebPullBook toolbar icon. Check metadata and volumes, pick a chapter range if you only want recent chapters, and choose your device in Reader Profile.

Step 3: Export & Save

Keep Safe Mode checked on long works, then click Pack EPUB. Finished books save under Downloads/WebPullBook/<Title>/ or your chosen folder.

Pin the Icon

Pin WebPullBook to your toolbar so opening the workspace from any story takes one click.

Pick Your Reader Once

Choose your e-reader profile once; WebPullBook remembers your selection across future books.

Enable Safe Mode on 100+ Chapters

Prevents temporary HTTP 429 blocks on shared novel hosts during long exports.

Save Series to Library

After your first export, click Save to Library so future updates download only new chapters.

3. Transfer to Your E-Reader or Reading App

Choose the export profile that guarantees covers, footnotes, and chapters render properly on your device:

Amazon Kindle

  • Send to Kindle (Email / Web / App): Use Kindle (Legacy) so WebPullBook exports classic EPUB 2 with 1200px JPEG images accepted cleanly by Amazon's converter.
  • USB via Calibre: Use Kindle (Modern) (EPUB 3 with pop-up footnotes), then let Calibre convert to KFX or AZW3 before transferring over USB.

Kobo, Tolino & PocketBook

  • Export using Kobo & E-Readers (EPUB 3 with 1080px JPEG images, full color preserved, and pop-up footnotes).
  • Copy the .epub via USB directly into your reader (or use Calibre's KoboTouch driver if you want automatic KePub conversion).

Phones, Tablets & Desktop

  • Use Modern Default for Apple Books, Thorium Reader, Calibre Viewer, Moon+ Reader, KOReader, or ReadEra.
  • Prefer reading with no ebook app at all? Switch Output Format to Single-File HTML and open it directly in any browser offline.

4. Common Setup Troubleshooting

Quick fixes for the three most frequent first-time installation questions:

Extension Vanished After Restarting Chrome or Edge

Unpacked Chromium extensions stay pointed to the folder you loaded. Make sure you unzipped the release into a permanent folder (not inside temporary Downloads cleanup or still inside the .zip file) and load it again.

Firefox Asks for Host Permission or Fails on Fetch

Firefox MV3 treats website access as an explicit user permission. Accept the status banner inside WebPullBook when prompted, or toggle website access on in about:addons → WebPullBook → Permissions.

Where Are Exported Books Stored?

Files land inside Downloads/WebPullBook/<Book Title>/ by default. You can customize subfolder tokens or—on Chrome, Edge, and Brave—click Choose PC Folder... under Advanced Options.

5. Running From Source & Developer Workflow

WebPullBook uses native ES modules with zero build step and zero runtime dependencies—the repository root loads directly as an unpacked extension in both Chromium and Firefox, while optional Node.js tooling validates every change locally.

Need private real-site E2E scripts while developing new parser adapters? Place them inside the gitignored .local-e2e/ directory—see Contributing for the full step-by-step developer guide.
