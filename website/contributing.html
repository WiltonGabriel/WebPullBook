Contributing to WebPullBook

WebPullBook was created and is maintained by Wilton Gabriel, and is open to contributions from the open-source community under the MIT License. The project uses native ES modules with no build step and no runtime dependencies, so you can load the repository folder directly in your browser and run unit checks with standard Node.js.

Ways to Contribute

Both code and non-code contributions help maintain the project.

1. Test Websites & Compatibility

Test WebPullBook on web novel platforms, blogs, or documentation sites and open a Pull Request updating docs/COMPATIBILITY.md (following the 4-tier classification and listing only site names, never URLs).

2. Report Bugs with Execution Logs

If an extraction or EPUB export fails, open the Logs tab in WebPullBook, click Download Log, and attach the file to a GitHub Issue using the Bug Report template.

3. Request New Site Layout Support

If a recurring CMS or theme cannot be extracted via generic heuristics, open a New Site Layout / Adapter Support issue describing the DOM selectors for the chapter list, chapter body, and volumes.

4. Improve the Generic Extractor

Following the General Compatibility First approach, improvements to BaseParser, GenericHtmlParser, or HtmlSanitizer are preferred over site-specific rules whenever a pattern is shared across sites.

5. Build Structural Parser Adapters

When a platform uses custom paginated JSON APIs or non-standard DOM structures, implement a subclass of BaseParser under src/parsers/ with anonymized HTML snapshot fixtures.

6. Cross-Browser & E-Reader Testing

Validate generated EPUB 2 and EPUB 3 files on Kindle, Kobo, PocketBook, Tolino, and mobile reading apps, or test the extension on Firefox 128+, Edge, and Brave.

Local Development & Testing

Linting and unit/snapshot tests run on the Node.js 22+ standard library without requiring npm install. Only the Chromium browser E2E test uses Playwright.

Developer Documentation (CONTRIBUTING.md)

See the contributor guide in the repository for instructions on creating a BaseParser subclass, adding anonymized HTML fixtures under tests/fixtures/, and running the pre-PR checklist.

AI Coding Agent Instructions (AGENTS.md)

The repository includes an AGENTS.md file for AI coding tools (Codex, Cursor, Claude Code, Antigravity, Copilot), documenting module responsibilities, SRP boundaries, MV3 CSP rules, and verification steps.
