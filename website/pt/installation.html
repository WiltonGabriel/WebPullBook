Instalação & Uso Básico

O WebPullBook já está publicado oficialmente no Firefox Add-ons (AMO) para Firefox 128+. A publicação na Chrome Web Store está prevista em seguida; durante a Beta, quem usa Chrome, Edge ou Brave pode instalar o pacote oficial via GitHub Releases sem etapa de compilação.

Instalar no Firefox Add-ons GitHub Releases (Chrome / Chromium) Todas as Versões & Checksums
Mozilla Firefox 128+ (Manifest V3)

1. Mozilla Firefox (128 ou Superior)

  1. Acesse a página do WebPullBook no Firefox Add-ons.
  2. Clique em Adicionar ao Firefox e confirme as permissões solicitadas.
  3. Atualizações assinadas são entregues automaticamente pelo Firefox Add-ons.
  4. Para Desenvolvedores: Compilações locais de desenvolvimento continuam podendo ser carregadas temporariamente em about:debugging#/runtime/this-firefox.
Chrome • Edge • Brave • Vivaldi • Chromium

2. Google Chrome e Navegadores Chromium

  1. Baixe o arquivo da versão em GitHub Releases e extraia em uma pasta fixa no computador.
  2. Abra chrome://extensions/ (ou edge://extensions/ / brave://extensions/).
  3. Ative o Modo do desenvolvedor no canto superior direito.
  4. Clique em Carregar sem compactação e selecione a pasta extraída que contém o arquivo manifest.json.

Como Utilizar

Fluxo básico após carregar a extensão no navegador:

1. Abra a Página da Obra

Acesse a página de índice de capítulos (ou um capítulo) no navegador. Se o site exigir login ou verificação anti-bot, conclua essa etapa na aba primeiro.

2. Abra o Workspace

Clique no ícone do WebPullBook na barra do navegador. A aba de trabalho abrirá lendo o DOM da aba ativa para preencher metadados, volumes e capítulos (aplicando a capa padrão caso a página não tenha imagem de capa).

3. Escolha o Perfil e Exporte

Selecione um Perfil de Leitor (como Kindle Antigo para Send to Kindle, Kindle Moderno para Calibre USB ou Kobo), marque os volumes ou capítulos desejados e clique em Empacotar EPUB.

Para Desenvolvedores: Git Clone & Atualização

Para desenvolvedores e contribuidores que executam a partir do código-fonte ou testam alterações, a pasta raiz do repositório pode ser carregada diretamente:

Usuários finais não precisam de Git — use o Firefox Add-ons ou baixe o pacote .zip pronto acima. Para atualizar manualmente no Chromium, extraia o novo .zip sobre a mesma pasta (ou execute git pull) e clique em recarregar em chrome://extensions/; configurações e obras na Biblioteca em chrome.storage.local são preservadas.
