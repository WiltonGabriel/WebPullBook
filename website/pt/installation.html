Instalação & Envio para Seu Leitor

Comece a salvar histórias em menos de dois minutos. No Firefox, a instalação é em um clique pelo Firefox Add-ons (AMO); no Chrome, Edge e Brave, basta baixar e descompactar o pacote oficial da Beta.

Instalar no Firefox Add-ons Baixar ZIP (Chrome / Edge / Brave) Todas as Versões & Checksums

1. Instale no Seu Navegador

Escolha seu navegador abaixo. Atualizações futuras mantêm suas configurações, Perfis de Leitor, regras por domínio e Biblioteca salvos.

Mozilla Firefox 128+ (Manifest V3)

Mozilla Firefox (128 ou Superior)

  1. Acesse a página do WebPullBook no Firefox Add-ons.
  2. Clique em Adicionar ao Firefox e confirme as permissões de acesso aos sites para leitura e extração.
  3. Fixe o ícone do WebPullBook na barra do navegador pelo menu de extensões para abrir com um clique.
  4. Se o Firefox exibir aviso de permissão ao abrir sua primeira obra, clique no botão do aviso ou libere o acesso em about:addons → Permissões.
  5. Atualizações: Chegam automaticamente assinadas pela Mozilla AMO.
Chrome • Edge • Brave • Vivaldi • Chromium

Google Chrome, Edge, Brave & Vivaldi (Beta)

  1. Baixe o arquivo .zip mais recente em GitHub Releases e extraia para uma pasta permanente (ex.: Documentos/Extensoes/WebPullBook/ — não apague nem mova essa pasta depois).
  2. Na barra de endereço, abra chrome://extensions/ (ou edge://extensions/ / brave://extensions/).
  3. Ative o Modo do desenvolvedor no canto superior direito.
  4. Clique em Carregar sem compactação e selecione a pasta extraída que contém manifest.json.
Atualizando ou Trocando de Computador Sem Perder Nada

Quando sair uma versão nova no Chromium, extraia o novo .zip por cima da mesma pasta (ou rode git pull) e clique no botão circular de recarregar em chrome://extensions/. Suas preferências, séries da Biblioteca e regras de domínio permanecem intactas no chrome.storage.local. Vai formatar ou trocar de PC? Use Opções Avançadas → Backup & Restauração Global para salvar tudo em JSON.

2. Crie Seu Primeiro Ebook & Dicas Rápidas

O fluxo simples da página aberta até o arquivo pronto, com quatro hábitos recomendados:

Passo 1: Abra a História

Entre na página do índice da história (ou em qualquer capítulo) em uma aba normal. Se o site exigir login ou verificação humana, conclua nessa aba primeiro.

Passo 2: Marque Capítulos e Perfil

Clique no ícone do WebPullBook. Confira os dados e volumes, selecione só um trecho se quiser, e escolha seu aparelho em Perfil de Leitor.

Passo 3: Exporte e Salve

Deixe o Modo Seguro ativo para obras grandes e clique em Empacotar EPUB. Os livros vão direto para sua pasta Downloads ou pasta escolhida.

Fixe o Ícone

Deixe o WebPullBook visível na barra do navegador para abrir o workspace com um único clique.

Defina Seu Perfil Uma Vez

Escolha seu perfil de e-reader uma vez; a extensão guarda essa escolha para os próximos livros.

Ative o Modo Seguro

Em livros com mais de 100 capítulos, reduz o risco de bloqueio HTTP 429 pelo site.

Salve na Biblioteca

Clique em Salvar na Biblioteca para depois baixar apenas os novos capítulos publicados.

3. Envie Para Seu Kindle, Kobo ou Celular

Dicas práticas para garantir capas nítidas, notas funcionando e organização correta em cada leitor:

Amazon Kindle

  • Send to Kindle (E-mail / Web / App): Use Kindle (Antigo) para gerar EPUB 2 com imagens JPEG a 1200px aceitas sem erro pelo conversor da Amazon.
  • Cabo USB via Calibre: Use Kindle (Moderno) (EPUB 3 com notas pop-up) e deixe o Calibre converter para KFX ou AZW3 antes de copiar para o Kindle.

Kobo, Tolino & PocketBook

  • Exporte com Kobo e Leitores Digitais (EPUB 3 com JPEG a 1080px, cores preservadas e notas pop-up).
  • Copie o .epub por cabo USB direto para o leitor (ou envie pelo Calibre se preferir conversão para KePub).

Celular, Tablet & Computador

  • Use Padrão Moderno para Apple Books, Thorium Reader, Calibre Viewer, Moon+ Reader, KOReader ou ReadEra.
  • Quer abrir sem instalar aplicativo? Escolha HTML Único Offline em Formato de Saída e leia direto no navegador.

4. Resolvendo Dúvidas Comuns de Instalação

Soluções rápidas para os três imprevistos mais comuns logo após instalar:

Extensão Sumiu ao Reiniciar o Chrome ou Edge

Extensões carregadas sem compactação apontam para a pasta no disco. Confira se você extraiu o .zip para uma pasta definitiva (e não abriu direto de dentro do ZIP ou de pasta temporária limpa pelo sistema) e carregue novamente.

Firefox Exibe Aviso de Permissão ao Carregar Site

O Manifest V3 do Firefox exige permissão explícita para acessar sites externos. Aceite pelo banner de alerta do próprio WebPullBook ou ative em about:addons → WebPullBook → Permissões.

Onde Ficam Salvos os Meus Ebooks?

Por padrão, vão para Downloads/WebPullBook/<Título>/. Você pode personalizar subpastas por tokens ou — no Chrome, Edge e Brave — clicar em Escolher Pasta no PC... nas Opções Avançadas.

5. Execução a Partir do Código-Fonte & Testes (Desenvolvimento)

O WebPullBook usa módulos ES nativos sem build nem dependências de runtime — a pasta do repositório já funciona direto no navegador, enquanto as ferramentas opcionais de Node.js validam qualquer alteração.

Para testar sites reais localmente sem comprometer URLs pessoais no Git, coloque scripts privados dentro da pasta ignorada .local-e2e/ — veja o passo a passo completo em Contribuir.
