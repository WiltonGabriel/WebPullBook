Comunidade & Engenharia

Como Contribuir com o WebPullBook

O WebPullBook utiliza módulos ES nativos sem etapa de compilação e sem dependências de runtime, permitindo carregar a pasta do repositório diretamente no navegador e rodar os testes unitários com Node.js padrão.

Formas de Contribuir

Tanto contribuições de código quanto testes e documentação ajudam a manter o projeto.

1. Testar Sites & Compatibilidade

Teste o WebPullBook em plataformas de web novels, blogs ou documentações e abra um Pull Request atualizando docs/COMPATIBILITY.md (respeitando as 4 categorias e listando apenas o nome do site, sem URLs).

2. Reportar Bugs com Logs de Execução

Se uma extração ou exportação EPUB falhar, abra a aba Logs no WebPullBook, clique em Baixar Log e anexe o arquivo em uma Issue no GitHub usando o modelo de Bug Report.

3. Sugerir Suporte a Novos Layouts

Se um CMS ou tema recorrente não puder ser extraído pela heurística genérica, abra uma issue com o modelo New Site Layout / Adapter Support informando os seletores CSS da lista de capítulos, texto e volumes.

4. Aprimorar a Camada Genérica

Seguindo a abordagem General Compatibility First, melhorias no BaseParser, GenericHtmlParser ou HtmlSanitizer têm prioridade sobre regras específicas quando um padrão é compartilhado por vários sites.

5. Criar Adaptadores Estruturais

Quando uma plataforma utiliza APIs JSON paginadas ou estruturas DOM específicas, implemente uma subclasse de BaseParser em src/parsers/ acompanhada de fixtures HTML anonimizadas.

6. Testes em Navegadores & E-Readers

Valide arquivos EPUB 2 e EPUB 3 gerados em aparelhos Kindle, Kobo, PocketBook, Tolino e aplicativos mobile, ou teste a extensão no Firefox 128+, Edge e Brave.

Desenvolvimento Local & Testes

As verificações de lint e testes unitários/snapshots rodam na biblioteca padrão do Node.js 22+ sem exigir npm install. Apenas o teste E2E no navegador Chromium utiliza Playwright.

Guia do Desenvolvedor (CONTRIBUTING.md)

Consulte o guia no repositório para instruções sobre criação de subclasses de BaseParser, adição de fixtures HTML anonimizadas em tests/fixtures/ e checklist de Pull Request.

Instruções para Agentes de IA (AGENTS.md)

O repositório inclui um arquivo AGENTS.md para ferramentas de programação com IA (Codex, Cursor, Claude Code, Antigravity, Copilot), documentando responsabilidades de módulos, limites SRP, regras MV3 CSP e etapas de verificação.
