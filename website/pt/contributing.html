Como Contribuir com o WebPullBook

O WebPullBook foi criado e é mantido por Wilton Gabriel, estando aberto às contribuições da comunidade open source sob a Licença GNU AGPLv3 (AGPL-3.0-or-later; versões até v1.6.1-beta permanecem historicamente sob a Licença MIT). O projeto utiliza módulos ES nativos sem etapa de compilação e sem dependências de runtime, permitindo carregar a pasta do repositório diretamente no navegador e rodar os testes unitários com Node.js padrão.

Formas de Contribuir — Foco em Desenvolvimento de Parsers

Ajudar a desenvolver, aprimorar e adicionar parsers (adaptadores de sites e heurísticas de extração) é a contribuição de maior impacto para expandir o suporte do WebPullBook a novas plataformas e layouts.

1. Desenvolver e Adicionar Parsers (src/parsers/)

Quando uma plataforma ou tema CMS utiliza APIs JSON paginadas, listas de capítulos via AJAX ou estruturas DOM próprias, implemente uma subclasse de BaseParser em src/parsers/, registre-a em src/parsers/index.js e adicione fixtures HTML anonimizadas.

2. Evoluir o Parser Heurístico Genérico

Seguindo o princípio General Compatibility First, melhorias no BaseParser, GenericHtmlParser ou HtmlSanitizer permitem que famílias inteiras de sites, blogs e domínios espelho funcionem automaticamente sem regras presas a um único domínio.

3. Mapear Seletores para Novos Parsers

Mesmo sem programar em JavaScript, você pode ajudar na criação de parsers inspecionando o HTML de um site (ou usando a ferramenta 🎯 Apontar) e abrindo uma issue New Site Layout / Adapter Support com os seletores CSS da lista de capítulos, texto e volumes.

4. Testar Sites & Atualizar a Compatibilidade

Teste o WebPullBook em plataformas de web novels, blogs ou documentações e abra um Pull Request atualizando docs/COMPATIBILITY.md (o site oficial sincroniza as tabelas automaticamente a partir desse arquivo).

5. Reportar Falhas de Extração com Logs

Se uma extração ou exportação EPUB falhar em determinado capítulo ou índice, abra a aba Logs no WebPullBook, clique em Baixar Log e anexe o arquivo em uma Issue no GitHub.

6. Validação em Navegadores & E-Readers

Valide arquivos EPUB 2 e EPUB 3 gerados em aparelhos Kindle, Kobo, PocketBook, Tolino e aplicativos mobile, ou teste a extensão no Firefox 128+, Edge e Brave.

Como Desenvolver e Adicionar um Novo Parser (Adaptador)

Todos os adaptadores herdam de BaseParser (src/core/base-parser.js) e utilizam pontuação estrutural de DOM (matchScore) para continuar funcionando mesmo quando um site muda de domínio.

Desenvolvimento Local & Testes

As verificações de lint e testes unitários/snapshots rodam na biblioteca padrão do Node.js 22+ sem exigir npm install. Apenas o teste E2E no navegador Chromium utiliza Playwright.

Guia do Desenvolvedor (CONTRIBUTING.md)

Consulte o guia no repositório para instruções sobre criação de subclasses de BaseParser, adição de fixtures HTML anonimizadas em tests/fixtures/ e checklist de Pull Request.

Instruções para Agentes de IA (AGENTS.md)

O repositório inclui um arquivo AGENTS.md para ferramentas de programação com IA (Codex, Cursor, Claude Code, Antigravity, Copilot), documentando responsabilidades de módulos, limites SRP, regras MV3 CSP e etapas de verificação.
