Features, Reader Profiles & Architecture

From one-click presets for Kindle and Kobo to adaptive throttling, local caching, and the zero-dependency extraction pipeline underneath.

1. Reader Profiles & Output Formats

Reader Profiles are fixed presets available in both the main Series panel and Advanced Options. Selecting a profile configures EPUB standard, pop-up footnotes, JPEG cover conversion, image resolution, compression, and typography together. Editing any field switches to Custom automatically so manual tweaks are preserved.

Reader Profile EPUB Standard Pop-up Footnotes Cover JPEG Image Optimization Max Resolution Recommended Target
Modern Default (modern) EPUB 3 Yes Yes Original (uncompressed) Original Phones, tablets, Apple Books, Thorium, Calibre Viewer
Kobo & E-Readers (kobo) EPUB 3 Yes Yes Compressed JPEG 1080px Kobo (including Clara/Libra Colour), Tolino, PocketBook
Kindle (Modern) (kindle-modern) EPUB 3 Yes Yes Compressed JPEG 1200px Calibre KFX/AZW3 conversion via USB, Kindle Colorsoft, modern apps

EPUB 2 & EPUB 3 (.epub)

Produces W3C-valid EPUB archives packaged locally with an uncompressed mimetype header first. EPUB 2 emits strict XHTML 1.1 and toc.ncx; EPUB 3 emits XHTML5, nav.xhtml landmarks, epub:type="footnote" pop-ups, and collection metadata.

Single-File HTML (.html)

Bundles cover, Table of Contents, and images as embedded data URIs inside one self-contained offline HTML document with clean reader typography and theme support.

Markdown & Plain Text (.md / .txt)

Exports normalized headings, paragraphs, emphasis, and scene separators free of navigation chrome—ideal for note vaults (Obsidian, Logseq) or minimal text archives.

2. Book Structure, Volumes & Output Organization

Fine-grained control over volume splitting, front and back matter, typography, and where exported files land on disk.

Front Matter, Colophon & Typography

  • Cover Page & Fallback Emblem (cover.xhtml): Fetches high-resolution covers (unwrapping WordPress Jetpack i0.wp.com resizing proxies), accepts local image uploads, or generates a branded default cover when missing. Alerts if a cover uses WebP/AVIF when JPEG conversion is off.
  • Information & Closing Pages (info.xhtml / end.xhtml): Customizable metadata sheet (title, author, language, genres, synopsis, source URL) and optional End-of-Book colophon with custom closing text.
  • Start-of-Book Table of Contents (nav.xhtml / toc.xhtml): Nested volume and chapter navigation placed upfront, with internal chapter links automatically rewritten to relative book paths.
  • Book Stylesheet Controls: Customize font family, base size, line height, paragraph spacing, text alignment, and indented paragraphs—or inspect the generated CSS live.

Volumes, Folder Layouts & Custom Folders

  • One File per Volume or Single Book: Automatically groups chapters by detected volume (with manual volume override and re-detection), exports separate volume books, or merges everything up to a configurable max chapter limit.
  • Path & Filename Templates: Organize downloads using tokens like %Root%, %Title%, %Filename%, %Author%, %Volume%, %Format%, and %Language% with illegal path character sanitization.
  • Browser Downloads or Direct PC Folder: Save into a structured Downloads subfolder via chrome.downloads, or grant access to a local folder in Chromium using showDirectoryPicker (FileSystemDirectoryHandle).

3. Curation, Text Cleaning & Media Pipeline

Inspect and clean content before saving, while strict binary checks keep images crisp and standards-compliant.

Preview, Quick Edit & Merge

Open any chapter in the preview modal to verify sanitized prose and word count, edit titles or paragraphs inline (marking it protected from cache overwrite), reverse order, select ranges via Shift+Click / Ctrl+Click, or combine open tabs via Merge Tabs.

Ad, Watermark & Regex Stripping

Removes scripts, inline handlers, ads, adjacent next/previous navigation links, decoded Cloudflare __cf_email__ spans, and hidden decoy text from inline <style> rules—plus custom literal lines or /regex/flags patterns per series.

Safe Image Validation & Fallbacks

Inspects magic bytes on every image (PNG, JPEG, GIF, WebP, AVIF, BMP), drops disguised HTML/SVG payloads or 1×1 pixels, preserves animated GIF/APNG/WebP, deduplicates identical assets by content hash, flattens transparent JPEGs on white, and applies temporary DNR Referer rules (slots 120..129) only when hotlink protection blocks anonymous fetches.

4. Safe Mode, Local Cache & Ongoing Library

Built to finish multi-hundred-chapter downloads reliably without hammering source servers or losing progress.

Adaptive Safe Mode & Pause Recovery

Toggle Safe Mode even mid-download for 1x sequential pacing, latency backoff, batch cooldowns, and HTTP Retry-After handling. Pause cleanly between chapters, cancel safely, or re-queue errors with Retry Failed.

Resumable IndexedDB Cache

Stores sanitized chapter XHTML in local IndexedDB (capped at 64 MB with automatic LRU cleanup and configurable 1–14 day TTL or disabled mode) so dropped connections resume immediately from completed chapters.

Library Tracking & Batch Updates

Track ongoing web novels in one unified grid or grouped by origin domain, check all saved series for newly released chapters, and export only unread chapters across updated books via Download Updates.

5. Under the Hood: Extraction & Security Pipeline

Every extraction runs locally as vanilla ES modules inside your browser—with zero bundler, zero build step, and zero runtime dependencies—combining user convenience tools with clean engineering boundaries.

Active-Tab Capture (sourceTabId)

Opening the workspace reads the already-rendered DOM from your active tab when available, avoiding redundant HTTP requests and respecting the session you already authenticated in the browser.

DOM Scoring & Universal Extractor

Adapters inheriting from BaseParser compete via structural matchScore. When no specialized layout matches, Universal Smart Extractor (generic-html) scores link clusters and prose density (Innermost Node Wins), crawls sequential "Next Chapter" links, or loads JavaScript pages via a single reusable background tab (TabRenderPool).

Pick Selectors & Strict Sanitization

Custom CSS selectors via interactive Pick stay scoped per domain in wpbDomainRules (falling back automatically if a custom list selector breaks). All extracted HTML passes through whitelist sanitization (HtmlSanitizer) and strict XML 1.0 serialization before CompressionStream builds the final ZIP container.
