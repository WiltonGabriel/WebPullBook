Features & Extraction Architecture

An overview of how WebPullBook extracts multi-chapter web content, handles dynamic pages, formats EPUB 2 and EPUB 3 archives, and manages local caching.

1. Extraction & Dynamic Page Handling

WebPullBook combines structural DOM scoring, heuristic discovery, and browser tab capture for both static HTML pages and client-rendered JavaScript sites.

Active-Tab DOM Capture

Clicking the toolbar icon reads the already-rendered DOM from the active tab (sourceTabId), avoiding an extra cold HTTP fetch on pages you already have open.

Generic Heuristic Extractor

Scores link clusters and prose density (using the "Innermost Node Wins" rule), supports <br>-separated paragraphs, and extracts JSON-LD @graph, Open Graph, and volume headings on generic HTML sites.

SPA / JavaScript Tab Mode

Detects unhydrated SPA shells and renders chapters in a single reusable background tab (TabRenderPool), waiting for DOM mutations to settle and pausing if an anti-bot challenge appears.

Visual Selector Picker (🎯 Pick)

In Advanced Options, click 🎯 Pick to select the chapter list, chapter body, or excluded elements directly on the page, or run the automatic selector assistant.

Per-Domain Selector Isolation

Custom CSS selectors and regex filters stay restricted to the current site session or saved Domain Rules, with automatic fallback to the native adapter if a custom list selector matches zero chapters.

Sequential "Next Chapter" Crawler

When a site does not have an index page, WebPullBook can start from a chapter URL and follow sequential "Next Chapter" links automatically.

2. Reader Profiles (Kindle, Kobo & Mobile)

Reader Profiles are fixed presets available in the Series tab and in Advanced Options. Picking a profile configures EPUB version, pop-up footnotes, cover JPEG conversion, image compression, resolution, and typography at once.

3. Book Structure, Curation & Image Pipeline

Options for organizing volumes, reviewing chapter text before packaging, and handling cover and inline images.

EPUB Structure & Default Cover

  • Cover Page & Default Cover Fallback (cover.xhtml): Uses the detected book cover, a local uploaded image, or automatically generates a default cover with the WebPullBook logo emblem, title, and author when no cover is found on the page.
  • Information Page (info.xhtml): Optional front page displaying title, author, language, chapter count, genre tags, source link, and synopsis.
  • Start-of-Book Table of Contents (nav.xhtml / toc.xhtml): Placed at the beginning of the book when enabled, supporting nested volumes.
  • End-of-Book Page (end.xhtml): Optional closing page with a custom message, book summary, source link, and generation date.
  • Pop-up Footnotes & Internal Links: Intra-chapter footnote anchors convert to EPUB 3 pop-up footnotes, and links between chapters in the same book rewrite to internal EPUB file paths.

Chapter Curation & Image Processing

  • Preview & Quick Edit: Preview any chapter and edit its title or paragraph text inline before exporting.
  • Merge Chapters & Merge Open Tabs: Combine checked chapters into one, or capture open browser tabs into a single anthology or separate volume files.
  • Volume & Range Selection: Toggle all volumes at once, or select individual items and ranges with Ctrl+Click and Shift+Click on volume chips and chapter rows.
  • Magic-Byte MIME Detection & Deduplication: Verifies binary image headers (PNG, JPEG, GIF, WebP, AVIF, BMP, SVG), drops HTML error pages returned as image URLs, retries HTTP failures anonymously, preserves animated GIF/APNG/WebP, and deduplicates identical images by content hash.

4. Safe Mode, Local Cache & Library

Tools for pacing requests on rate-limited servers, resuming interrupted downloads, and tracking ongoing works.

Adaptive Safe Mode & Manual Latency

Toggle Safe Mode during an export to use 1x sequential requests, dynamic latency backoff, batch rest pauses, and Retry-After headers—or set a manual delay between chapters (0–30,000 ms) in Advanced Options.

7-Day IndexedDB Cache

Downloaded chapters are saved in local IndexedDB (up to 64 MB, configurable TTL from 1 to 14 days) so interrupted downloads can resume without re-fetching completed chapters.

Library & Batch Updates

Save series to your local Library (viewed unified or grouped by site), check for newly published chapters, and export unread chapters across tracked works with Download Updates.

WebPullBook

Open-source Manifest V3 browser extension for extracting web novels, serialized fiction, articles, and open tabs into EPUB 2/3, HTML, Markdown, and TXT ebooks.
