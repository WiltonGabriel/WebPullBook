Features, Reader Profiles & Architecture

From one-click presets for Kindle and Kobo to adaptive throttling, local caching, and the zero-dependency extraction pipeline underneath.

1. Reader Profiles & Output Formats

Reader Profiles are fixed presets available in both the main Series panel and Advanced Options. Selecting a profile configures EPUB standard, pop-up footnotes, JPEG cover conversion, image resolution, compression, and typography together. Editing any field switches to Custom automatically so manual tweaks are preserved.

Reader Profile EPUB Standard Pop-up Footnotes Cover JPEG Image Optimization Max Resolution Recommended Target
Modern Default (modern) EPUB 3 Yes Yes Original (uncompressed) Original Phones, tablets, Apple Books, Thorium, Calibre Viewer
Kobo & E-Readers (kobo) EPUB 3 Yes Yes Compressed JPEG 1080px Kobo (including Clara/Libra Colour), Tolino, PocketBook
Kindle (Modern) (kindle-modern) EPUB 3 Yes Yes Compressed JPEG 1200px Calibre KFX/AZW3 conversion via USB, Kindle Colorsoft, modern apps
Kindle (Legacy) (kindle) EPUB 2 No Yes Compressed JPEG 1200px Send to Kindle email/web/app (compatible with Amazon's cloud converter)

Legacy Default (legacy) EPUB 2 No Yes Compressed JPEG 1080px Older Sony Reader, early Nook, CoolReader, legacy firmwares
Custom (custom) User-defined User-defined User-defined User-defined User-defined Activated automatically when any Advanced Option is edited

EPUB 2 & EPUB 3 (.epub)

Produces W3C-valid EPUB archives packaged locally with an uncompressed mimetype header first. EPUB 2 emits strict XHTML 1.1 and toc.ncx; EPUB 3 emits XHTML5, nav.xhtml landmarks, epub:type="footnote" pop-ups, and collection metadata.

Single-File HTML (.html)

Bundles cover, Table of Contents, and images as embedded data URIs inside one self-contained offline HTML document with clean reader typography and theme support.

Markdown & Plain Text (.md / .txt)

Exports normalized headings, paragraphs, emphasis, and scene separators free of navigation chrome—ideal for note vaults (Obsidian, Logseq) or minimal text archives.

2. Workspace Tools: Volumes, Curation, Covers & Tab Merging

Fine-grained control inside the main Series panel before packing: organize volumes, edit chapter text or URLs, customize covers, or combine open browser tabs.

Auto & 4-Way Manual Volumes

  • Automatic Grouping: Detects multi-volume TOCs and supports one-click re-detection via Try Finding Volumes.
  • Quick Selection: Toggle whole volumes, filter chapters, or select exact ranges using Ctrl+Click and Shift+Click.
  • Set Volumes Manually: Split every N chapters, assign ranges by table row number (#), tag current checked chapters, or apply batch multi-line rules (1-50: Arc 1).

Preview, Quick Edit, Merge & URL Editor

  • Chapter Preview & Word Count: Inspect sanitized prose, footnotes, word counts, and image counts before packaging.
  • Inline Quick Edit: Fix chapter titles or paragraphs inside the modal—saved edits stay protected from accidental cache overwrite.
  • Batch Adjustments: Merge side stories or interludes into a chapter, reverse chapter order, filter lists, or open Edit URLs to fix broken chapter links.

Covers, Book Structure & Merge Tabs

  • Cover Controls: Fetch high-resolution covers (unwrapping WordPress Jetpack proxies), upload local artwork, reload the original cover, or generate a clean default cover automatically.
  • Front & Back Matter: Include a clickable start-of-book TOC, customizable Information Page (choose which metadata fields appear), and optional closing End-of-Book colophon.
  • Merge Open Tabs: Bundle open HTTP/HTTPS tabs into a single anthology or separate standalone books, with drag-free ordering and preview.

3. Inside Advanced Options & Diagnostic Logs

Advanced Options spans six independent configuration modules—each with its own Restore Default reset button—plus a dedicated Logs tab. Modifying any field switches your Reader Profile to Custom so manual setups stay preserved.

Files & EPUB Standard

Choose a direct PC folder in Chromium (showDirectoryPicker) or structured Downloads subfolders with naming tokens (%Root%, %Title%, %Filename%, %Author%, %Volume%, %Format%, %Language%), control Save-As prompts, switch EPUB 3/2, toggle pop-up footnotes, and pick which fields appear on Information and End pages.

Extraction, Parser & Domain Rules

Let automatic DOM scoring pick an adapter or override manually, capture CSS selectors live on any page with Pick (list, chapter body, exclusions), verify matches inline with Test selectors, strip repeating lines via plain text or /regex/flags filters, save isolated Domain Rules, and toggle sequential "Next Chapter" crawling.

Network, SPA & Resilience

Toggle Safe Mode anytime during downloads (1x sequential pacing, jitter, batch cooldowns, and HTTP Retry-After), set an independent manual delay slider (0–30000 ms), pause automatically on HTTP 429/503, continue past broken pages and re-run Retry Failed, skip HTTP 404s, or enable SPA / JavaScript Tab Mode.

Images & Cover Processing

Inspects magic bytes on every asset (PNG, JPEG, GIF, WebP, AVIF, BMP), rejects disguised HTML/SVG payloads or 1×1 tracking pixels, deduplicates identical images by content hash, preserves animated GIF/APNG/WebP, flattens transparent JPEGs on white, scales and compresses illustrations, and supports optional <svg> cover wrappers.

Typography & Book Stylesheet (CSS)

Fine-tune reading comfort inside generated EPUB and HTML files: pick the default font family, base size, line height, paragraph spacing, text alignment, and printed-book first-line indentation—or inspect and edit the resulting stylesheet live before packing.

Global Backup, Reset & Logs Tab

Export or import all global preferences alongside saved Domain Rules as a single portable JSON file, reset all Advanced Options in one click, and inspect timestamped extraction events inside the filterable Logs tab with one-click Copy Log and Download Log.

4. Library, Resumable Cache & Reading Comfort

Track ongoing stories for weeks without losing your place, pick up interrupted downloads automatically, and read the interface comfortably day or night.

Ongoing Library & Site Grouping

Save any series in Library (viewable unified across all origins or grouped by domain), run Check All to detect new releases, and package only unread chapters across updated books via Download Updates.

7-Day IndexedDB Resume Cache

Stores sanitized chapter XHTML in local IndexedDB (64 MB cap with automatic LRU eviction and configurable 1–14 day TTL or disabled cache) so dropped connections resume immediately via Resume Download or Pack Cached Only.

4 Interface Themes & Bilingual UI

Switch cleanly between Light, Dark, Sepia, and Midnight themes plus instant English and Portuguese (Brazil) localization with zero page flicker and minimalist SVG controls.

5. Under the Hood: Extraction & Security Pipeline

Every extraction runs locally as vanilla ES modules inside your browser—with zero bundler, zero build step, and zero runtime dependencies—pairing everyday usability with strict security boundaries.

Active-Tab Capture (sourceTabId)

Opening the workspace from the toolbar captures the live DOM already rendered in your active tab when available, reducing extra network requests and working inside your browser's own session.

DOM Scoring & Universal Extractor

Adapters inheriting from BaseParser compete via structural matchScore. When no layout adapter matches, the Universal Smart Extractor (generic-html) scores link clusters and prose density (Innermost Node Wins), crawls sequential "Next Chapter" links, or loads JavaScript shells via a single reusable background tab (TabRenderPool).

Strict Sanitization, DNR & ZIP32

Extracted HTML passes through whitelist sanitization (HtmlSanitizer) and XML 1.0 serialization (stripping XSS vectors, hidden decoy CSS classes, and invalid codepoints), uses ref-counted DNR Referer slots (120..129) only when hotlink protection blocks anonymous image retries, and builds the final archive with native CompressionStream.
