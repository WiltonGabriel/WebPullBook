Support & Troubleshooting

Frequently Asked Questions (FAQ)

Answers regarding e-reader profiles, website extraction, rate-limit handling, and privacy.

E-Readers, Kindle & Kobo Profiles

What is the difference between Kindle (Legacy) and Kindle (Modern)?

Kindle (Legacy) generates an EPUB 2 (2.0.1) archive with classic toc.ncx navigation, 1200px JPEG images, and no EPUB 3 HTML5 tags. It is intended for Amazon's Send to Kindle service (email, web uploader, or mobile app), which can reject certain EPUB 3 tags.

Kindle (Modern) generates an EPUB 3 archive with semantic nav.xhtml, series collection metadata, 1200px JPEG images, and EPUB 3 Pop-up Footnotes. Choose it when converting or transferring via Calibre (USB → KFX or AZW3) or reading in EPUB 3 apps.

Which profile should I use for Kobo, Tolino, or PocketBook?

Choose Kobo & E-Readers. It outputs EPUB 3 with pop-up footnotes, series/volume metadata, and 1080px JPEG optimization while preserving full color on color E-Ink displays.

Why did my Reader Profile switch to "Custom" automatically?

Reader Profiles are fixed presets. Whenever you modify any individual setting under Advanced Options (including options outside typography or images, such as manual request latency), the selector switches to Custom so your manual edits are preserved. Selecting a named profile again restores all fields of that profile.

What happens when a book page does not have a cover image?

When WebPullBook cannot detect a cover image on the source page (or when creating a book via Merge Tabs), it automatically generates a default cover with the WebPullBook logo emblem, the book title, and the author. You can also upload a local image file, click Generate Cover after editing the title, or click Clear Cover if you prefer no cover.

Website Extraction, Selectors & SPA Mode

What should I do if a website loads 0 chapters or misses chapter content?

WebPullBook tries active-tab DOM capture, SPA tab rendering, and heuristic selector detection automatically. If a custom layout still needs manual adjustment:

1. Open Advanced Options → Extraction, Parser & Rules.
2. Click 🎯 Pick next to Chapter list CSS selector or Chapter content CSS selector to click the element directly on the open web page, or click Auto-detect selectors.
3. Click Save for Domain to keep the rule for that domain, then click Load Series again.

How can I package a story or blog that has no Table of Contents page?

Two options are available for sites without an index page:

• Sequential "Next Chapter" Crawling: Open the first chapter you want to include and load its URL in WebPullBook. When Follow "Next Chapter" link automatically is enabled (default), the generic extractor follows the next-chapter links in order.
• Merge Open Tabs: Open the chapters or articles in browser tabs, click Merge Tabs in WebPullBook's top bar, reorder or preview them, and export them as a single book or separate files.

Why did the export pause with an Anti-Bot (Cloudflare) or Rate-Limit banner?

When a website responds with a Cloudflare challenge or HTTP 429/503 rate limit, WebPullBook pauses the queue to avoid repeated blocked requests. Click Open page to verify ↗ on the banner, complete the check in that browser tab, enable Safe Mode, and click Resume. Already downloaded chapters remain cached in IndexedDB.

Privacy, Beta Status & Troubleshooting

Does any data leave my browser?

All HTML parsing, XHTML sanitization, image conversion, and ZIP/EPUB packaging run locally inside your browser. No data is sent to a WebPullBook server or third-party analytics service. Your browser only makes direct HTTP/HTTPS requests to the websites and image CDNs you choose to download from. See the Privacy & Permissions Policy.

Why is WebPullBook not on the Chrome Web Store or Firefox Add-ons yet?

WebPullBook is currently in open-source Beta. During Beta, packages are distributed on GitHub Releases while features and testing are stabilized ahead of store submission.

How do I report a bug or request support for a website layout?

Open the Logs tab inside WebPullBook and click Download Log (or Copy Log), then open an issue on GitHub Issues using the Bug Report or New Site Layout / Adapter Support template.
