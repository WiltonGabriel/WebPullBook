Frequently Asked Questions (FAQ)

Answers regarding e-reader profiles, website extraction, rate-limit handling, and privacy.

E-Readers, Profiles & Formats

What is the difference between Kindle (Legacy) and Kindle (Modern)?

Kindle (Legacy) generates an EPUB 2 (2.0.1) archive with classic toc.ncx navigation, 1200px JPEG images, and no EPUB 3 HTML5 tags. It is built for Amazon's Send to Kindle service (email, web uploader, or mobile app), which can reject certain EPUB 3 markup.

Kindle (Modern) generates an EPUB 3 archive with semantic nav.xhtml, series collection metadata, 1200px JPEG images, and EPUB 3 Pop-up Footnotes. Choose it when converting or transferring via Calibre (USB → KFX or AZW3) or reading in EPUB 3 apps.

Which profile should I use for Kobo, Tolino, PocketBook, or phones?

For Kobo, Tolino, or PocketBook, choose Kobo & E-Readers (EPUB 3 with pop-up footnotes, series/volume metadata, and 1080px JPEG images preserving color on color E-Ink screens). For phones, tablets, Apple Books, or Thorium Reader, choose Modern Default to keep original uncompressed images.

Why did my Reader Profile switch to "Custom" automatically?

Reader Profiles are fixed presets. Whenever you modify any individual setting under Advanced Options (including options outside typography or images, such as manual request latency), the selector switches to Custom so your manual edits are preserved. Selecting a named profile again restores all fields of that profile.

What happens when a book page has no cover or uses a WebP cover?

When WebPullBook cannot detect a cover image (or when building a book via Merge Tabs), it automatically generates a clean default cover with the WebPullBook emblem, title, and author. You can also upload a local image file, click Generate Cover after editing metadata, or click Clear Cover. If a detected cover is WebP/AVIF while JPEG cover conversion is turned off, a warning note reminds you so older readers don't reject it.

Can I download only part of a 1,000+ chapter story or export separate volume books?

Yes. Use the First Chapter / Last Chapter dropdowns, search filter, Shift+Click range selection, or click individual Volume chips to keep only the range you want. Choose 1 File per Volume to generate separate EPUBs per volume, or Single File to pack everything (with nested volume navigation) up to your configured chapter limit.

When should I export Single-File HTML, Markdown, or Plain Text instead of EPUB?

Choose Single-File HTML when you want one offline web page (with embedded cover and images) that opens in any browser with no e-reader app needed. Choose Markdown (.md) for note-taking tools like Obsidian or Logseq, or Plain Text (.txt) for minimal lightweight archives.

Extraction, Selectors & SPA Pages

What if the website I read isn't listed on the Compatibility page?

Try pasting its URL or clicking the WebPullBook toolbar icon anyway. Universal Smart Extractor (generic-html) is a core focus of WebPullBook: it automatically discovers chapter lists, follows sequential "Next Chapter" links, renders JavaScript pages via background tab when static HTML is empty, and offers the point-and-click Pick tool for any custom layout.

What should I do if a website loads 0 chapters or misses chapter content?

Open Advanced Options → Extraction, Parser & Rules, click Pick next to Chapter list CSS selector or Chapter content CSS selector to click directly on the open page (or click Auto-detect selectors), test with Test selectors, and click Save for Domain before clicking Load Series again. Domain rules stay isolated so they never interfere with other websites.

How do I remove recurring translator notes, banners, or ads from chapters?

Built-in sanitization automatically removes scripts, ads, adjacent chapter navigation links, and hidden CSS decoy classes. For recurring text specific to one translation or site, add either an Excluded elements CSS selector (via Pick) or lines/regular expressions (like /[Translator Note:.*?]/gi) inside Text / Regex strip filter in Advanced Options.

How can I package a story or blog that has no Table of Contents page?

Two options work out of the box:

• Sequential "Next Chapter" Crawling: Open the first chapter you want to include and load its URL in WebPullBook. When Follow "Next Chapter" link automatically is enabled (default), the generic extractor follows next-chapter links in sequence.
• Merge Open Tabs: Open the chapters or articles in browser tabs, click Merge Tabs in WebPullBook's top bar, reorder or preview them, and export them as one book or standalone files.

Does WebPullBook work on sites where I need to sign in first?

Yes, as long as your logged-in browser session can already read the standard HTML text in an open tab. Sign in normally in a regular browser tab first, then open WebPullBook from that tab. WebPullBook cannot bypass paid subscriptions you do not own, encrypted DRM readers, or <canvas> pixel-only chapters.

Ongoing Series, Errors & Saving Files

How do I track an ongoing series and download only newly released chapters?

After loading or exporting a story, click Save to Library. Later, open the Library tab and click Check All to scan tracked series for newly published chapters, or click Download Updates to export only the unread chapters in one batch.

Why did the export pause with an Anti-Bot (Cloudflare) or Rate-Limit banner?

When a website returns a Cloudflare check or HTTP 429/503 rate limit, WebPullBook pauses immediately so your IP is not flooded with failed requests. Click Open page to verify on the banner, solve the verification check in that browser tab, keep Safe Mode enabled, and click Resume. Completed chapters remain cached locally in IndexedDB.

What happens if a few chapters fail or my internet disconnects mid-download?

Already downloaded chapters stay cached in IndexedDB (default 7-day retention). You can click Retry Failed after a partial export, or reopen the session from Library → Recent Downloads & Local Cache and click Resume Download (or Pack Cached Only).

Can I save books directly to a custom folder on my computer?

Inside your Downloads folder, custom relative folder templates work on both Firefox and Chromium (for example WebPullBook/%Author%/%Title%). In Chrome, Edge, and Brave, you can also click Choose PC Folder in Advanced Options to write directly to any folder via showDirectoryPicker.

Privacy, Releases, Licensing & Bug Reports

Does any data leave my browser?

Within the WebPullBook browser extension, all HTML parsing, XHTML sanitization, image conversion, and ZIP/EPUB packaging run locally inside your browser with no backend server, no telemetry, and no analytics—your browser only makes direct HTTP/HTTPS requests to the websites and image CDNs you choose to download from. Separately, this public documentation website uses GoatCounter for cookieless, aggregated page-view counting without personal tracking or cookies. See the Privacy & Permissions Policy.

Why is WebPullBook not on the Chrome Web Store yet?

WebPullBook is officially published on Firefox Add-ons (AMO) for Mozilla Firefox 128+. Chrome Web Store submission is planned next; during open-source Beta, Chrome, Edge, and Brave users can install the release package directly from GitHub Releases.

What license does WebPullBook use?

WebPullBook is licensed under the GNU Affero General Public License v3.0 (AGPL-3.0-or-later).

How do I report a bug or request support for a website layout?

Open the Logs tab inside WebPullBook and click Download Log (or Copy Log), then open an issue on GitHub Issues using the Bug Report or New Site Layout / Adapter Support template.
